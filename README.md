# СтудСеть

> Учебный проект — визуальный макет закрытой соцсети для студентов колледжей и ВУЗов.  
> Создан в рамках учебной практики студентами ОАТК: **Ефремов И.И.** и **Беляев М.А.**

---

##  Что это

**СтудСеть** — концепт соцсети для учебных заведений. Идея: у каждой группы, направления и курса есть свой чат; преподаватели публикуют объявления в каналах; студенты общаются в клубах по интересам.

Проект реализован **исключительно как визуальный макет**. Никакой серверной части, авторизации, отправки сообщений и работы с реальными данными нет. Всё статично, все кнопки и поля — «нарисованы».

---

##  Цель проекта

1. Освоить семантическую вёрстку на HTML5.
2. Научиться организовывать CSS по слоям (переменные → база → компоненты → экраны).
3. Разобраться с современными возможностями CSS: кастомные свойства, `color-mix()`, `grid`, `flex`, медиа-запросы.
4. Попробовать минимальный JS — только для переключения экранов, без логики.

---

##  Стек технологий

| Технология | Зачем |
|---|---|
| **HTML5** | семантическая разметка (header, nav, main, section, article, footer) |
| **CSS3** | оформление, темы, адаптив |
| **Vanilla JS** | переключение экранов через `data-nav` |
| **Google Fonts (Inter)** | шрифт интерфейса |
| **DiceBear Avatars** | генерация демо-аватарок |

Никаких фреймворков, сборщиков и зависимостей — чистый HTML/CSS/JS.

##  Как запустить

Просто открой `index.html` в браузере. Никаких сборок и установок не требуется.

**Или через локальный сервер** (рекомендуется для разработки):

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен npx)
npx serve
```

Затем открой `http://localhost:8000`.

##  Экраны приложения

Макет содержит **5 экранов**, переключаемых через верхнее меню и иконки в шапке:

| Экран | Как открыть | Что там |
|---|---|---|
| **Чаты** | вкладка «Чаты» или логотип | Трёхколоночный мессенджер |
| **Поиск** | вкладка «Поиск» | Карточки студентов |
| **Клубы** | вкладка «Клубы» | Карточки клубов по интересам |
| **Профиль** | клик по аватару в шапке | Информация о пользователе |
| **Настройки** | иконка-шестерёнка | Переключатели настроек |
